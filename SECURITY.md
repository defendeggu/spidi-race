# Sicherheit

## Eine Sicherheitslücke melden

Bitte **kein öffentliches Issue** eröffnen. Melde Sicherheitslücken vertraulich über GitHub:
**Security → Report a vulnerability** ([direkt zum Formular](https://github.com/defendeggu/spidi-race/security/advisories/new)).

Hilfreich sind eine kurze Beschreibung, die betroffene Version und die Schritte, mit denen sich das Problem nachvollziehen lässt. Spidi Race ist ein Hobbyprojekt: Ich antworte so bald wie möglich, kann aber keine festen Fristen zusagen.

## Unterstützte Versionen

Sicherheitskorrekturen gibt es nur für die jeweils neueste Version auf `main`.

## Einsatzbereich

Spidi Race ist für das **Heimnetz** gedacht: Der Server hat keine Anmeldung, und jeder im Netz kann Netzwerkspiele eröffnen und Ranglisten-Einträge schicken. Den Server nicht ungeschützt ins Internet stellen.
